# Build LifeLens – AI Voice-Based Personal Memory & Insight Agent

Create a production-ready full-stack AI application called LifeLens.

## Vision

LifeLens is a voice-first AI life companion that remembers, understands, and helps users learn from their life experiences.

Users should be able to call the AI, speak naturally, record memories, store decisions, retrieve experiences, generate insights, and visualize personal growth over time.

LifeLens must feel like a futuristic AI operating system rather than a simple chatbot.
